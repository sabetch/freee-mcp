# Taxes

## 概要

税区分

## エンドポイント一覧

### GET /api/1/taxes/codes

操作: 税区分一覧の取得（廃止予定）

説明: 概要 税区分一覧を取得する 税区分コード（code）は、取引の作成（POST /api/1/deals）や振替伝票の作成（POST /api/1/manual_journals）などで税区分を指定する際に tax_code として利用します。 注意点 このAPIは廃止予定のため非推奨です。/api/1/taxes/companies/{company_id}（指定した事業所の税区分一覧の取得）をご利用ください。 本APIは事業所の設定に依存しない共通の税区分マスタを返します。事業所ごとの使用設定（available）や表示カテゴリ（display_category）を確認する場合は /api/1/taxes/companies/{company_id} をご利用ください。 API利用上の非推奨税区分（課税、非課税、不課税、輸出等、未選択、課税8%）は返りません。

### レスポンス (200)

- taxes (必須): array[object]
  配列の要素:
    - code (必須): integer(int64) - 税区分コード。取引の作成（POST /api/1/deals）や振替伝票の作成（POST /api/1/manual_journals）などで税区分を指定する際に tax_code として利用します。 例: `21` (最小: 1, 最大: 2147483647)
    - name (必須): string - 税区分名（システム識別名） 例: `sales_with_tax`
    - name_ja (必須): string - 税区分名（日本語表示用）。freee会計の画面上で表示される名称です。 例: `課税売上`

### GET /api/1/taxes/codes/{code}

操作: 税区分の取得

説明: 概要 指定したコードに対応する税区分を取得する 注意点 存在しないコード、またはAPI利用上の非推奨税区分（課税、非課税、不課税、輸出等、未選択、課税8%）のコードを指定した場合は404エラーが返ります。

### パラメータ

| 名前 | 位置 | 必須 | 型 | 説明 |
|------|------|------|-----|------|
| code | path | はい | integer(int64) | 税区分コード。/api/1/taxes/codes（税区分一覧の取得）または /api/1/taxes/companies/{company_id}（指定した事業所の税区分一覧の取得）で取得できる code を指定します。 |

### レスポンス (200)

- tax (必須): object
  - code (必須): integer(int64) - 税区分コード。取引の作成（POST /api/1/deals）や振替伝票の作成（POST /api/1/manual_journals）などで税区分を指定する際に tax_code として利用します。 例: `21` (最小: 1, 最大: 2147483647)
  - name (必須): string - 税区分名（システム識別名） 例: `sales_with_tax`
  - name_ja (必須): string - 税区分名（日本語表示用）。freee会計の画面上で表示される名称です。 例: `課税売上`

### GET /api/1/taxes/companies/{company_id}

操作: 指定した事業所の税区分一覧の取得

説明: 概要 指定した事業所の税区分一覧を取得する 税区分コード（code）は、取引の作成（POST /api/1/deals）や振替伝票の作成（POST /api/1/manual_journals）などで税区分を指定する際に tax_code として利用します。事業所で利用できる税区分と使用設定（available）を確認するために本APIをご利用ください。 注意点 一覧には事業所の設定で「使用しない」となっている税区分も含まれます。available=true を指定すると、使用する設定の税区分のみに絞り込めます。 display_category が null の税区分は、税率を持たない税区分（未選択、対象外など）です。
